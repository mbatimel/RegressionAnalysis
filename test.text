
### 1. **Полиномиальная регрессия (Polynomial Regression)**
   - Может классифицировать зависимости как **линейные, квадратичные, кубические и т. д.**  
   - Использует полиномиальные признаки: \( Y = b_0 + b_1X + b_2X^2 + b_3X^3 + ... + \varepsilon \).  
   - Чем выше степень полинома, тем сложнее зависимость.  

### 2. **Логистическая регрессия (Logistic Regression)**
   - Не является "регрессией" в классическом смысле, но используется для **классификации** зависимостей.  
   - Определяет, относится ли зависимость к одному из двух классов (бинарная классификация).  

### 3. **Piecewise Regression (Сегментированная регрессия)**
   - Классифицирует зависимости по **разным диапазонам X**.  
   - В каждой области используется **своя модель** (например, в одном диапазоне линейная, в другом квадратичная).  

### 4. **Регрессия с разными функциями активации**
   - Использование **нейросетевых методов** позволяет автоматически подбирать **нелинейные зависимости**.  
   - Примеры: **нейронные сети**, **decision trees + regression** (CART).  

### 5. **Support Vector Regression (SVR)**
   - Использует **ядра (kernel functions)** для нахождения сложных зависимостей.  
   - Позволяет определять **линейные и нелинейные зависимости**.  

### 6. **Ридж и лассо-регрессия (Ridge & Lasso)**
   - Позволяют **отфильтровать незначимые зависимости**, оставляя только важные признаки.  
   - Полезны для **определения степени зависимости** каждой переменной.
